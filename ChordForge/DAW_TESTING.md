# ChordForge DAW Testing & Verification Manual

This document provides step-by-step instructions to test and verify **ChordForge VST3** in major DAWs on Windows x64.

---

## 1. Ableton Live (Live 11 / 12)

### Prerequisites
1. Build ChordForge Release VST3:
   ```cmd
   cmake --build build --config Release --target ChordForge_VST3
   ```
2. Verify file exists at:
   `C:\Program Files\Common Files\VST3\ChordForge.vst3`
3. Launch Ableton Live. In **Preferences -> Plug-Ins**, ensure "Use VST3 Plug-In System Folders" is set to **On**. Click **Rescan** if needed.

### Routing Setup
Because ChordForge is a MIDI generator:

1. **Create Track 1 (ChordForge)**:
   - Insert `ChordForge` from the Plug-ins browser onto MIDI Track 1.
   - Set the Monitor switch to **In** (or **Auto** with record arm active).

2. **Create Track 2 (Synthesizer / Instrument)**:
   - Insert any instrument (e.g., Grand Piano, Wavetable, Serum, Vital) onto MIDI Track 2.
   - In Track 2's **MIDI From** dropdown, select **1-ChordForge**.
   - In the secondary dropdown under "MIDI From", select **ChordForge**.
   - Set Track 2's Monitor switch to **In**.

### Functional Verification Checklist
- [ ] **GUI Display**: Open ChordForge editor. Verify the dark hardware-styled window opens cleanly at 720×480 with no graphical glitches.
- [ ] **Audition Button**: Click "▶ Audition". Verify that Track 2 produces audio corresponding to the selected chord.
- [ ] **DAW Playhead Sync**:
  - In ChordForge, leave Trigger Mode set to "Sequencer / Host".
  - Press Spacebar in Ableton Live to start playback.
  - Verify that ChordForge steps through slots `[ I ] [ V ] [ vi ] [ IV ]` in sync with Ableton's beat grid and tempo.
  - Verify that the mini piano visualizer displays the active chord notes.
- [ ] **MIDI Trigger Mode**:
  - Change Trigger Mode to "Root Trigger".
  - Play note C3 on your MIDI keyboard. Verify a voiced C Major chord sounds on Track 2.
  - Play note D3. Verify a D chord sounds.
- [ ] **MIDI Export**:
  - Click "Export MIDI (.mid)" and save `test.mid` to Desktop.
  - Drag `test.mid` from Windows File Explorer into an empty Ableton MIDI track. Verify notes are placed on the timeline with exact durations.
- [ ] **State Persistence**:
  - Change Key to "E" and Scale to "Harmonic Minor".
  - Save the Ableton Live project (`test_chordforge.als`).
  - Close Ableton, re-open the project, and inspect ChordForge. Verify that Key=E and Scale=Harmonic Minor are preserved.

## 2. FL Studio (FL Studio 20 / 21 / 24)

### Prerequisites
1. In FL Studio, open **Options -> Manage plugins**.
2. Run a scan with "Verify plugins" enabled.
3. Verify that **ChordForge** appears in the plugin list with type "Synth / Generator".

### MIDI Routing Setup (Port Assignment)
FL Studio routes MIDI between generator plugins using internal MIDI Ports:

1. **Insert ChordForge**:
   - In the Channel Rack, click `+` and choose `ChordForge`.
2. **Configure Output Port**:
   - In the ChordForge wrapper window, click the **Gear Icon (Detailed settings)** at the top left.
   - Click the **VST wrapper settings** tab (plug + gear icon).
   - Under **MIDI**, set **Output port** to `10` (or any available port number).
3. **Insert Sound Generator**:
   - In the Channel Rack, add `FL Keys` (or any VST synth).
   - Open its wrapper settings (Gear Icon -> VST wrapper settings).
   - Under **MIDI**, set **Input port** to `10` (matching ChordForge's output port).

### Functional Verification Checklist
- [ ] **Channel Rack Trigger**: Select ChordForge in the Channel Rack. Press spacebar or keys on your computer keyboard (Q, W, E).
- [ ] **Transport Sequencer**: In Song mode, place a pattern on the playlist and press Play. Verify that FL Keys plays the chords generated by ChordForge.
- [ ] **Randomizer**: In ChordForge, click "🎲 Randomize". Verify that the chord slots update to a new diatonic progression and audio immediately reflects the new harmony.
- [ ] **Voice Leading**: Toggle "Smooth Voice Leading" On and Off. Verify that with Voice Leading On, successive chords avoid large pitch leaps.
- [ ] **Project Save / Reload**: Save the FL Studio project (`.flp`), reload it, and verify that all progression slots and settings restore faithfully.

## 3. Troubleshooting & Diagnostics

| Symptom | Probable Cause | Resolution |
| :--- | :--- | :--- |
| Plugin does not appear in DAW | VST3 file not copied to Common Files | Run `cmake --build build --config Release --target ChordForge_VST3` or manually copy `.vst3` to `C:\Program Files\Common Files\VST3\`. |
| No sound produced in instrument track | MIDI routing not configured | In Ableton, verify "MIDI From" is set to ChordForge. In FL Studio, verify Output Port of ChordForge matches Input Port of Instrument. |
| Crash on project open | Incompatible binary architecture | Ensure your DAW is 64-bit and the plugin was built with Visual Studio x64 target (`-A x64`). |
| Chords don't step on playback | DAW playhead position not transmitted | Ensure DAW transport is running (Play button pressed). Some DAWs require active timeline motion to send PPQ positions. |
